## 📺 What the Demo Videos Cover

The demonstration videos walk through the primary user journeys and technical workflows of the Student 360 ecosystem:

### 1. 🎓 Student Portal Walkthrough
* **Sleek Dashboard:** Demonstrating the orange-and-dark glassmorphic UI, displaying real-time GPA, exam schedules, and alerts.
* **GitHub Integration:** Showcasing how the app pulls coding data to render language distributions and commit activity heatmaps.
* **Gamification & Accomplishments:** Showing the badge and rewards system for student achievements and rules adherence.

### 2. 🛡️ Admin Portal Demonstration
* **Institutional Dashboard:** Overview of general statistics like average GPAs, active violations, and student enrollment trends.
* **Student Directory:** Management tools, search filters, and profile editing.
* **Leaderboards:** Highlighting the GitHub coding contributor leaderboard across all students.
* **Exam Management:** Scheduling exams, setting up invitation tokens, and checking results.

### 3. ⚙️ Electron App & API Integration
* **Automated Exam Grading:** Demonstrating how student answers are collected and sent via the `/api/submit-result` endpoint.
* **Database Synced Results:** Showing live result creation and Instant updates in both the student portal and admin dashboard.
* **Disciplinary Tracking:** A demo of how browser tab-switch violations are logged during remote exam attempts.
